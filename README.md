# 海平面變化地圖

一個以公開 DEM 高程圖磚即時計算的互動式海平面情境地圖。

除了六個預設情境，也可使用水平滑桿在 −120 m 至 +66 m 之間，以 0.1 m 精度自訂海平面。

## 啟動

這是純靜態網站。因瀏覽器安全限制，請不要直接雙擊 `index.html`，改用本機 HTTP 伺服器：

```powershell
python -m http.server 8000
```

然後開啟 <http://localhost:8000>。

## 情境

- +1 m：未來暖化情境探討
- +5 m：長期海平面上升
- +7.4 m：格陵蘭冰蓋完全融化
- +58 m：南極洲冰蓋完全融化
- +66 m：全球陸地冰完全融化的概略情境
- −120 m：末次冰盛期的海平面

## 方法與限制

正值會標出 DEM 高程大於現今海平面且低於情境高度的像素；負值則標出海平面以下、情境海平面以上的像素。這是地形門檻示意，不會計算水體連通性，也未納入堤防、潮汐、風暴潮、河流、排水或地層下陷，不能作為防災或工程依據。
